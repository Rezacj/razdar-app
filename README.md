# 🔐 رازدار – گاوصندوق دیجیتال امن شما

**خداحافظی با فراموشی رمزها و استرس لو رفتن اطلاعات!**

رازدار امن‌ترین و ساده‌ترین راه برای نگهداری تمام رمزهای عبور، اطلاعات بانکی، کدهای امنیتی و یادداشت‌های خصوصی شماست. همه چیز فقط و فقط روی گوشی خودتان ذخیره می‌شود و کلیدش هم فقط در دستان شماست.

---

## ✨ امکانات کلیدی

- 🛡️ **امنیت آفلاین و ضد سرقت:** بدون اینترنت، بدون سرور، بدون ردیابی.
- 🤖 **ورود با چهره یا اثر انگشت:** هیچ‌کس جز شما نمی‌تواند وارد گاوصندوقتان شود.
- 🔐 **قفل الگو (Pattern Lock):** ورود با کشیدن الگوی اختصاصی.
- 🔑 **ابزار ساخت رمز قوی:** رمزهای پیچیده و غیرقابل حدس.
- 📸 **گاوصندوق اسناد و عکس‌ها:** عکس کارت ملی و مدارک محرمانه.
- 💾 **پشتیبان‌گیری رمزنگاری‌شده:** با یک نسخه پشتیبان امن.
- 🔔 **اعلان‌های هوشمند:** نشانگر خوانده نشدن و بروزرسانی لحظه‌ای.
- 🎨 **ساده، شیک و دوست‌داشتنی:** طراحی مدرن با تم تاریک و روشن.
